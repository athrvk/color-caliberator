- Room not dark enough — try again with less ambient light

Windows
Right-click .icc → Install Profile
Win+R → colorcpl → Devices tab → select display
Tick "Use my settings for this device" → Set as default

Mac
System Settings → Displays → select display → Color Profile
Click the dropdown → "Customise…" → + → pick the .icc file
Or apply immediately (temporary, resets on logout):
dispwin -d1 color-calibrator.icc

Linux (X11)
dispwin -d1 color-calibrator.icc (temporary)
dispwin -d1 -I color-calibrator.icc (permanent)

Linux (Wayland)
Copy to ~/.local/share/icc/ → activate via colormgr
